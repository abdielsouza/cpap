# Coleção Pessoal de Análises e Pesquisas (CPAP)

> Um projeto criado por mim para reunir minhas análises de dados e pesquisas sobre problemas do mundo real em um só lugar.

Este repositório reúne projetos independentes de **análise de dados e pesquisa aplicada**, desenvolvidos a partir de dados públicos, bases abertas e outras fontes de informação.

A proposta é investigar perguntas, explorar evidências, identificar padrões, documentar limitações e transformar dados em conclusões que possam ser verificadas e reproduzidas.

---

## Sobre a coleção

Ao longo dos meus estudos em **ciência de dados** (principalmente durante a época da faculdade), comecei a perceber que alguns dos projetos mais interessantes não surgem necessariamente de um dataset pronto acompanhado de uma pergunta.

Muitas vezes acontece o contrário:

> **existe uma pergunta interessante; É necessário descobrir quais dados podem ajudar a respondê-la.**

Essa coleção nasceu dessa ideia.

Cada pesquisa parte de um problema ou pergunta específica e passa por diversas etapas de análise e processamento. Essas costumam ser:

1. Pergunta
2. Pesquisa
3. Aquisição
4. Auditoria
5. Limpeza
6. Análise Exploratória
7. Investigação
8. Visualização
9. Interpretação
10. Relatório e Publicação
