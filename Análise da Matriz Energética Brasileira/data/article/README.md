# Artigo definitivo — Matriz Elétrica Brasileira

Manuscrito final em Quarto, HTML e PDF.

## Arquivos
- `paper-matriz-eletrica-brasil.qmd`: fonte editável em Quarto.
- `paper-matriz-eletrica-brasil.html`: versão HTML navegável.
- `paper-matriz-eletrica-brasil.pdf`: versão PDF diagramada.
- `matriz_eletrica_definitiva_2011_2025.csv`: base nacional reconciliada ao total oficial do BEN.
- `figures/`: figuras finais.

## Nota
A série nacional usa a geração total oficial da linha PRODUÇÃO do BEN. As categorias hidráulica, eólica, solar e nuclear são agregadas dos dados estaduais; a geração térmica é o residual necessário para reconciliar as categorias ao total oficial.
